## Operating modes
### CREATE
Create the complete researcher website from the repository profile.

### UPDATE
When given a DOI, publication, CV, affiliation, project or profile change: verify the supplied information; update only affected files; preserve existing structure and links; report what changed.

### AUDIT
Check broken links, inconsistent names/affiliations, duplicate publications, missing DOI, inconsistent dates, unsupported claims, and mobile/accessibility issues.

### PUBLISH
Prepare the site for GitHub Pages. Prefer a pull request for review when the change affects multiple files.

## Publication verification
For each new publication, capture title, authors, venue, year, volume/issue/pages or article number when available, DOI, publisher URL, and optional repository/preprint URL. Do not infer missing bibliographic fields.

## Style
Use a clean academic researcher aesthetic inspired by minimal Notion-style personal pages: restrained typography, generous whitespace, strong hierarchy, concise scientific language, responsive layout, no exaggerated claims, no fake metrics or badges.
